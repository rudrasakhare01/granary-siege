# Granary Siege
Combinatorics resource-strategy game (Discrete Mathematics ISE-2, Track A:Gamified Application Game).

## Run
Open `index.html` in any type of browser. No install needed.

## Files
- ` Game logic.js` - math solvers (pigeonhole, inclusion-exclusion, C/P) and SVG visuals
- `game.js` - game state, rounds, scoring, sandbox lab, UI wiring 
- ` Game style.css` - styling and cursor-reactive borders
