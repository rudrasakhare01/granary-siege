# Granary Siege
Combinatorics resource-strategy game (Discrete Mathematics ISE-2, Track A).

## Run
Open `index.html` in any browser. No install needed.

## Files
- `logic.js` - math solvers (pigeonhole, inclusion-exclusion, C/P) and SVG visuals
- `game.js` - game state, rounds, scoring, sandbox lab, UI wiring
- `style.css` - styling and cursor-reactive borders
